開業費（繰延資産・全期間）

開業費は経費合計には入れていません。何年でいくら償却するかは決算時に決めます（任意償却）。「少額減価償却特例」の分は、その日付の年の経費（消耗品費など）に入っています。

「按分後」は金額×事業使用割合。決算書には按分後の金額を書きます。

同期（スマホ ⇄ パソコン）

記録・設定・領収書画像を非公開リポジトリに保存し、開いたときと変更したときに他の端末と合わせます。同じ記録を両方で直した場合は新しい方が残ります。削除も同期されます。
トークンの作り方: GitHub → 右上アイコン → Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token。Repository access は「Only select repositories」で keihi-data を選び、Permissions の Repository permissions で Contents: Read and write にして生成。表示された github_pat_… を上に貼り付けて「接続テスト」。有効期限（最長1年）が切れたら作り直して貼り替えます。

ルールの覚え書き
・ネット通販やメールで受け取った領収書＝電子取引。データ保存が義務。スクショでもOK（日付・金額・相手先が読めること）。
・紙でもらったレシート＝紙のまま保管でOK。写真は控えとして。紙を捨てるには「スキャナ保存」の要件が必要なので、迷ったら紙は捨てない。保存期間は7年。
・10万円未満→消耗品費で一括。10万円以上30万円未満→少額減価償却特例（青色・年300万円まで）。30万円以上→減価償却。
・飲食は1人あたり¥5,000未満なら会議費。5,000円以上でも実質「会議」なら会議費でよいが、人数・議題・インボイス番号を残す。
・1年以内のサービスの年払い（サーバー等）は支払時に一括経費でOK（短期前払費用）。

危険な操作

この端末の中身だけ消します。同期先には残るので、次の同期で戻ってきます。
